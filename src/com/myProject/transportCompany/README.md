# Uppgift 3: Transportföretag (Avancerad)

## Beskrivning

### Designa ett system för ett transportföretag som hanterar fordon, chaufförer, rutter och leveranser.

## Krav

• Vehicle – typ (lastbil, skåpbil), registreringsnummer, lastkapacitet

• Driver – namn, körkortsklasser, schema

• Route – startpunkt, destination, distans

• Delivery – kund, last, status

• TransportCompany – koordinerar allt

## Funktionalitet
• Planera rutter och tilldela fordon/chaufförer

• Hantera leveransstatus (pågår, levererad, försenad)

• Hålla koll på fordonsservice

• Visa reseloggar och statistik

## Utmaning

Implementera ett system för att optimera rutter baserat på distans och tillgänglighet.
